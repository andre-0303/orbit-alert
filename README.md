# 🌍 OrbitAlert

### Plataforma Inteligente de Previsão e Resposta a Desastres Naturais com Dados Satelitais

O **OrbitAlert** é uma plataforma desenvolvida para monitoramento, previsão e resposta a desastres naturais utilizando **dados satelitais em tempo real**, **inteligência artificial** e **visualização geográfica interativa**.

O projeto foi desenvolvido como parte do **Global Solution FIAP**, com o objetivo de criar soluções tecnológicas de impacto social, auxiliando governos e populações na prevenção de eventos climáticos extremos como:

* 🌊 Enchentes
* ⛰️ Deslizamentos de terra
* ☀️ Secas severas

---

## 📌 Sobre o Projeto

O OrbitAlert utiliza informações provenientes de satélites de instituições como **NASA** e **ESA (European Space Agency)** para analisar condições ambientais e identificar padrões de risco.

Por meio de algoritmos de **Inteligência Artificial**, a plataforma realiza análises preditivas capazes de antecipar possíveis desastres naturais e emitir alertas preventivos para autoridades e cidadãos.

Além disso, o sistema apresenta um **dashboard interativo com mapa de risco**, permitindo uma visualização clara das regiões vulneráveis.

---

## 🚀 Principais Funcionalidades

### 📡 Coleta de Dados Satelitais em Tempo Real

Integração com bases de dados espaciais e ambientais para monitoramento contínuo do território.

### 🤖 Inteligência Artificial para Predição

Análise de padrões climáticos e ambientais para prever:

* Enchentes
* Deslizamentos
* Secas

### 🚨 Sistema de Alertas Automáticos

Envio de alertas preventivos para:

* Prefeituras
* Defesa Civil
* População local

### 🗺️ Dashboard Interativo

Visualização geográfica de áreas de risco através de mapas dinâmicos e indicadores em tempo real.

### 🌐 Integração Internacional

O OrbitAlert considera integração com a **Carta Internacional Space and Major Disasters**, ampliando o acesso a imagens satelitais emergenciais durante grandes catástrofes naturais.

---

## 🛰️ Como Funciona

O fluxo da plataforma ocorre em 4 etapas:

1. **Coleta de Dados**

   * Dados capturados via satélites (NASA e ESA).

2. **Processamento Inteligente**

   * Modelos de IA analisam padrões ambientais e históricos.

3. **Predição de Risco**

   * O sistema calcula probabilidades de ocorrência de desastres.

4. **Resposta e Alerta**

   * Alertas são emitidos para órgãos responsáveis e população.

## ⚙️ Como Executar o Projeto

### Clone o repositório

```bash
git clone https://github.com/andre-0303/orbit-alert.git
```

### Acesse a pasta do projeto

```bash
cd orbitalert
```

### Instale as dependências

```bash
npm install
```

### Execute o projeto

```bash
npm run dev
```

A aplicação estará disponível em:

```bash
http://localhost:5173
```

## 🎯 Objetivo do Projeto

O principal objetivo do OrbitAlert é **reduzir impactos causados por desastres naturais através de prevenção inteligente**, fornecendo informações estratégicas para tomadas de decisão rápidas e eficientes.

A proposta busca unir:

* Tecnologia espacial
* Inteligência Artificial
* Dados climáticos
* Impacto social

para tornar cidades mais preparadas diante de eventos extremos.
